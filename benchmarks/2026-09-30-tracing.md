# Opt-in pipeline tracing

`MASH_TRACE=1` enables application-only JSON tracing on stderr. The subscriber
excludes dependency targets; instrumented functions skip all arguments. Safe
fields include process/request IDs, fixed operation/backend labels, HTTP status,
request elapsed milliseconds and typed error kinds. Span creation/closure events
provide the stage hierarchy and busy/idle timing. Busy time is not wall latency;
parallel and blocking work must be interpreted with request elapsed time.

The current spans cover the shared core, local/combined search, model loading,
query embedding, lexical/vector retrieval, scoring/reranking, indexing,
embedding rebuilding, parsing/application, HTTP authorization/backend work and
the CLI worker client. Request context and subscribers propagate to blocking
workers and scoped parser threads. Tests exercise concurrent isolation,
parser inheritance, query/path/history/credential exclusion, safe failures and
CLI stdout. An actual stdio MCP initialize/status/shutdown exchange also passed
with tracing enabled.

To inspect a direct local search:

```bash
MASH_TRACE=1 mash search cbioportal --local --no-worker 2>trace.jsonl
```

For repeated in-process searches, enable the same variable when launching
`mash mcp`. Enable it on `mash serve --server-config server.toml` to inspect
HTTP/backend work. Worker stderr is suppressed; traced replies now provide
correlated execution time and bounded internal stage summaries, including
inference. Full span events remain available through direct execution or MCP.
HTTP and worker correlation are implemented; broader fleet measurements remain
open in `mash-c0d.9`.

## HTTP correlation follow-up (2026-10-01)

Each traced shared HTTP call generates a random 128-bit ID, sent as
`x-mash-trace-id` and recorded as `trace_id` on the client `shared_http_request`
span. The server records it on `http_request`; its backend spans inherit that
context. IDs describe individual wire calls, so concurrent context fetches and
index upload calls remain distinct under their existing application parents.
Status, outcome and wall time include response decoding on the client.

The server accepts exactly one header containing 32 lowercase hexadecimal
characters. Missing, invalid, oversized or duplicate values receive a fresh
local ID; arbitrary header text is never recorded. Correlation does not affect
authentication, group routing or JSON payloads. With tracing disabled the client
sends no correlation metadata and neither side requests random bytes. Failure
to obtain random bytes leaves the trace field absent without failing the request.

Contracts exercise real HTTP transport and authenticated Axum middleware:
concurrent authorized/unauthorized calls have unique paired IDs and matching
status codes; malformed and duplicate headers remain bounded; query, identity,
credential and response canaries are excluded. A separate transport contract
checks successful typed responses, malformed response JSON, and actual absence
of headers with client tracing disabled. These local contracts do not establish
fleet overhead or worker cross-process propagation.

## Release cached-worker control (2026-10-02)

Production Rust source `2664be7`, optimized LLVM release profile (opt-level3,
16 codegen units), binary SHA256
`dafc71d229f6ed00e8e421048cba7187242cb234866d7b2c260052df98e91ddc`.
Xenia reported16 logical CPUs on AMD EPYC9645 hardware. Sampled one-minute
load averages ranged13.14–14.92; CPU/power policy and concurrent workloads were
not controlled. Installed models were AllMiniLML6V2Q (384 dimensions) and
jinaai/jina-reranker-v1-turbo-en. Capture pins include every installed model
asset, metadata, binary, script, configuration, source files and indexed DB.

The fixed synthetic workload has50 two-turn Claude threads,100 canonical
messages and100 vectors. Ten subjects crossed with five actions give50 distinct
queries. After two excluded traced warmups, each query runs both thread and
message search with limit5, tracing off/on in counterbalanced pair and unit
order. Every CLI invokes ordinary search; the harness supplies no result cache
and retains normal worker caches. The traced replies identify one worker across
all traced samples. Models stay loaded; these are warm CLI wall times,
including process startup, IPC and JSON serialization.

| Result unit | Samples per mode | Off median / p95 | On median / p95 | Median paired on-minus-off |
| --- | ---: | ---: | ---: | ---: |
| Threads | 50 | 190.17 / 336.24 ms | 202.36 / 277.81 ms | +6.77 ms |
| Messages | 50 | 88.59 / 121.93 ms | 89.15 / 126.39 ms | +1.56 ms |

All100 complete ranked-JSON comparisons match; untraced stderr is empty.
The100 measured traced requests plus two warmups have unique correlation IDs
and bounded stage summaries. Nine local stage names appear; each summary has
positive calls, total_us>=max_us, matching request/PID and no repeated stage.
Trace output is4,348–4,358 bytes per measured call and excludes the full query,
history canary and configured source/model paths. Nested stage times are
inclusive and must not be summed as CPU or request wall time.

Paired differences vary substantially: threads −294.89 to+192.70ms; messages
−123.80 to+61.55ms. Lower traced thread p95 is not evidence that tracing speeds
up search. This single busy-host synthetic comparison establishes the exercised
diagnostic/output contracts and records observed costs; it does not establish a
statistical overhead bound, real-corpus relevance, cold-start latency, remote
search, native Mac/Core ML behavior or fleet performance. It cannot satisfy
`mash-c0d.8.10` latency acceptance. No inference/search settings were changed
and no further tuning follows from this control.

Reproduce with a fresh output directory and a short persistent Unix-socket
temporary directory:

```bash
python3 tools/benchmark-worker-tracing.py \
  --binary /absolute/path/to/release/mash \
  --models /absolute/path/to/installed/models \
  --worker-temp-dir /absolute/short/temp-dir \
  --output /absolute/path/to/new/capture
```

The script never overwrites a capture or downloads models. Setup failures are
retained separately: initial expectations assumed50 rather than100 embeddings
and `local-hybrid` rather than the actual local `hybrid` mode. Both were corrected
before comparative sampling; the final control also uses a short worker temp
path. Final artifact:
