# Learned affinity with thread-local evidence

Registered after the four high-recall sweeps failed evaluation precision. Inspection is restricted to calibration errors. High-cosine false positives include different release versions, UI components and team-building subjects; this motivates distinguishing concrete subjects rather than further cosine-radius tuning. The prior installed Jina query/document reranker diagnostic was negative and is not repeated.

This is a **supervised prototype**, a change from the earlier unsupervised clustering family. Train only on decisive labels from the same 104 calibration threads. At runtime, use one thread's current prompts, visible answers and the cached joint-turn Code 4 2048/Voyage 4 1024 vectors. No other-thread text/statistics, turn IDs, provider/node identities, raw vocabulary identities, generative LLM calls or additional inference enter the features. Learned coefficients are global frozen parameters, like other trained models; this is not a claim of unsupervised learning.

Features: raw/smoothed dense cosine, thread-local word/character TF-IDF cosines for prompts/answers/joint text, token overlap, identifier/number overlap and availability, prompt/answer length ratios and log lengths, and chronological separation. Preserve all visible assistant segments. Thread-local TF-IDF fitting may use the thread's unlabeled turns, including pairs not in the reference sample; it never uses their verdicts. Ambiguous judgments remain excluded from fitting/scoring.

Use five folds grouped by calibration thread, ensuring no thread appears in both training and validation within a fold. Register 64 Optuna TPE trials (seed 20261009) over logistic regression versus small histogram gradient-boosted trees, dense-only versus hybrid features, regularization, tree size and decision threshold. Fit scaling only on each fold's training rows. Optimize simultaneous precision >82%, recall >90%, distant recall >80% on out-of-fold predictions; among feasible settings choose precision, then F1. Freeze one setting and fit on all calibration pairs before computing any evaluation metric. Evaluate once on the same separate 52-thread reused-development subdivision. This remains exploratory, agent-labeled and adaptive; confirmation stays sealed.

Convert thresholded symmetric affinities into overlapping cliques with a deterministic greedy edge cover: every emitted group has at least two turns and all member pairs meet the threshold. Cover remaining edges with two-turn groups. Verify that co-membership predictions exactly equal thresholded edge decisions. Report group-size distribution and two-turn-group fraction so pair-only fragmentation cannot masquerade as useful clustering. This graph cover avoids inventing transitive relationships unsupported by the affinity model. It is a batch prototype per changed thread, not yet a production or incremental implementation.

Use cached vectors only; no additional API spend. Persist the selected model, complete Optuna trials, fold contracts, feature/source/matrix/annotation hashes, private predictions and aggregate-only MLflow records. Publish both evaluation quality and limitations in the LaTeX paper. Do not relabel errors, change pair inclusion or promote the model to production based on reused-development point estimates.

Related methodology: [Kummerfeld et al., ACL 2019](https://aclanthology.org/P19-1374/) formulates conversation disentanglement with reply-structure graphs. Our within-thread subject-affinity task differs from separating interleaved speakers, so this is methodological inspiration, not a transfer claim. [Logistic regression](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html) and [histogram gradient boosting](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html) use existing scikit-learn dependencies.
