\section{Supervised affinity with grouped calibration}
The preceding experiments fail evaluation precision despite improving distant
recall. Calibration-only error inspection finds some high-cosine false matches
with different concrete subjects, including release versions and UI components.
We register a supervised affinity experiment, drawing methodological inspiration
from conversation-disentanglement reply graphs \cite{kummerfeldAffinity}.
Our within-thread subject-affinity labels differ from that task, so this is not
a transfer-performance claim. The earlier negative installed Jina diagnostic
is not repeated.

We retain all 104 calibration histories and 52 development evaluation histories.
Five calibration histories have only ambiguous judgments, leaving 99 histories
and 597 decisive pairs for fitting (409 related, 188 unrelated). Five folds are
grouped by thread. No thread crosses a fold's training/validation boundary, and
no evaluation thread enters cross-validation. Scaling is fitted independently
on each fold's training rows. Sixty-four seeded Optuna TPE trials compare logistic
regression and small histogram gradient-boosted trees \cite{sklearnAffinity},
using either four dense cosine features or a hybrid with thread-local lexical,
identifier, length and chronology features. We optimize the same simultaneous
point-estimate targets using out-of-fold predictions and freeze one setting
before evaluation. No additional embedding inference or generative LLM call
is made, and confirmation remains sealed.

Evaluation yields 176 true positives, 37 false positives, 17 false negatives and
66 true negatives, excluding 50 ambiguous judgments. Distant recall is 45/54,
versus 38/54 for the reference. All three strict targets are met, but with small
margins. The exploratory 95\% paired thread-bootstrap F1-gain interval is
$[-1.50,+4.10]$ percentage points. These reused-development, agent-authored
outcomes do not establish statistically confirmed superiority or performance
on new users' data.

The selected model is dense-only logistic regression with $C=.1$; the hybrid
lexical hypothesis does not yield the selected winner. Let $c_C,c_V$ denote raw
Code 4 2048-dimensional and Voyage 4 1024-dimensional cosines, and $s_C,s_V$
their cosines after existing branch-aware smoothing ($\alpha=.10$, window 4).
Absorbing scaling into the fitted coefficients gives
\[
p=\sigma(-.66711404c_C+2.33697363c_V+5.23130780s_C+7.26932672s_V-9.07758591).
\]
Pairs with $p\geq .525$ receive an edge. The sigmoid output is an affinity score,
not a probability calibration guarantee. Correlated predictors make causal
interpretation of coefficient magnitudes inappropriate. The negative raw-Code
coefficient also prevents interpreting this as simple positive-weight vector
concatenation. Runtime uses only the current thread and frozen learned weights.

A deterministic greedy clique cover forms overlapping groups from accepted
edges; remaining edges receive two-turn groups. Every within-group pair must
have an edge, preventing unsupported transitive relations. Full graph replay
verifies co-membership for all pairs, not only labeled pairs. The 52 evaluation
histories produce 3,704 groups, of which 3,068 (82.83\%) have two turns; 636 are
larger and the maximum size is 41. This fragmentation is a material limitation:
pair-level gates do not establish useful thematic groups, topic labels or
representative thread vectors. The method is a batch per-changed-thread research
prototype, not a production or incremental implementation.

The recorded driver time is 26.7 seconds, excluding final Optuna persistence and
previous embedding inference. Both fixed Voyage vector spaces are required,
increasing embedding work relative to the single-model reference. The experiment
costs no additional API inference. Verification rebuilds all 156 feature matrices,
checks provenance and fold separation, refits from calibration data, reconstructs
all groups and confusion counts, and validates all 64 trials and the finished
MLflow run. A typed JSON affine-logistic scorer agrees with sklearn within
$10^{-12}$. It removes the original CLI pickle's module-name dependency while
preserving the original artifact and hashes. Ruff, ty and all 171 Python tests
pass. The candidate manifest records exact coefficients and the frozen baseline
and production model remain unchanged.
