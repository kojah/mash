# Original-message support on unchanged topic groups

Frozen before corpus outcomes, 2026-10-02. P0
`mash-c0d.19.2.20.8.3.3.3.9.1`. The preceding audited experiment found
516 single-block groups with no eligible labels; 359 contain multiple original
ready messages. Test support granularity, not new clustering or word ranking.

Reuse the same 162 QMSum training meetings, 88,336 original source identities,
84,434 ready sources, 8,196 physical blocks, audited lexical-average trees and
fixed-eight display groups. Same source counts, static stoplist, letter rule,
c-TF-IDF times corpus block IDF, <=40% global block DF, top eight and lexical
ties. Corpus background and all score denominators stay physical-block based.
Only change the >=2 distinct-member-block support gate to >=2 distinct-original-
message support. Each original source ID appears exactly once; count presence,
not token repetitions or overlapping context copies. Blocks with raw-fallback
geometry grant no evidence. Single-source and fewer-than-two-term proposals
remain explicit. Adjacent messages are not independent human judgments.

The block-gated helper must reproduce every term, rank, score and block DF in
the previous frozen baseline. Original message counts may recover labels in
single-block groups but do not prove semantic correctness. Evaluate original
native topic-name token overlap only after labels are fixed. Retain unknown/
mixed-source and empty-name accounting, unchanged full source denominators.
Capture all labels, unique supporting original IDs, recovered/remaining empty
groups, and small label examples. No inference/download/LLM, custom stopword,
threshold/window/weight sweep, gold features or held-out data.

Require exact complete non-timing repeat, unchanged begin/end source pins,
independent scalar original-count/DF/score/rank/proxy audit, and stage timing
plus external RSS/PSS with disclosed scope. Performance measurements are label
research, not production ingestion. Quality/coding-session labels, multi-tag
membership, semantic ancestry, guided-search gains, online/global lifecycle,
edits/deletions/restart, <=10% full-ingestion loss and selected executable
Python/Rust parity remain promotion gates.
